\# Bug 08 — Гарчигт HTML тэмдэгт бичихэд давхар escape хийгдэж "\&lt;script\&gt;" гэж харагддаг



\*\*Severity:\*\* Low

\*\*Олдсон аялал:\*\* Saboteur — Гарчигт `<script>` оруулж HTML оролтыг зориуд туршсан.

\*\*Орчин:\*\* Opera 137.0.6036.63, Node.js v24.22.1, http://localhost:3000



\## Урьдчилсан нөхцөл (Preconditions)

Апп ажиллаж байгаа.



\## Reproduce хийх алхмууд

1\. `http://localhost:3000` хуудсыг нээх

2\. Гарчиг талбарт `<script>` бичээд "Нэмэх" дарах

3\. Хүснэгтийн гарчиг баганыг харах

4\. `curl.exe -i http://localhost:3000/api/books` ажиллуулж хадгалагдсан утгыг харах



\## Хүлээгдэж буй үр дүн (Expected)

Хүснэгтэд оруулсан текст шууд `<script>` гэж харагдах ёстой (скрипт

ажиллахгүй, гэхдээ текст хэвээр).



\## Бодит үр дүн (Actual)

Хүснэгтэд `\&lt;script\&gt;` гэж кодчилсон текст харагдсан. Скрипт ажиллаагүй

тул аюулгүй, гэхдээ хэрэглэгчид буруу текст харагдаж байна. Утга сервер

талд нэг удаа, UI талд дахин escape хийгдэж давхар кодчилогдож байна.

буруу дүгнэсэн байсан; Session 2-д дахин шалгахад давхар escape болох нь

тогтоогдсон.
