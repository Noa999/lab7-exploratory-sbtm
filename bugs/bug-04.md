# Bug 04 — "Хуучин хувилбар" (/old) хуудас HTTP 500 алдаа өгдөг

**Severity:** Medium
**Олдсон аялал:** Back Alley — UI-ийн гол урсгалаас гадуурх "Хуучин хувилбар" линкийг сониуч занаар дарж үзэхэд илэрсэн.
**Орчин:** Chrome browser, Node.js, http://localhost:3000

## Урьдчилсан нөхцөл (Preconditions)
Апп энгийн байдлаар ажиллаж байгаа.

## Reproduce хийх алхмууд
1. `http://localhost:3000` хуудсыг нээх
2. Хуудасны доод хэсэгт байгаа "Хуучин хувилбар" линк дээр дарах
3. Үр дүнг ажиглах
4. Нэмэлтээр: `curl -i http://localhost:3000/old` командыг ажиллуулж
   HTTP статус кодыг шалгах

## Хүлээгдэж буй үр дүн (Expected)
"Хуучин хувилбар" линк дарахад алдаагүй хуудас (эсвэл хэрэв функц
идэвхгүй бол тодорхой, ойлгомжтой мессеж) харагдах ёстой. HTTP 500
(серверийн дотоод алдаа) хэзээ ч хэрэглэгчид шууд харагдах ёсгүй.

## Бодит үр дүн (Actual)
Линк дарахад хар дэвсгэртэй, "Internal Server Error" гэсэн ердийн
browser-ийн алдааны хуудас гарч ирэв. `curl -i`-ээр баталгаажуулахад
сервер HTTP/1.1 500 статус кодыг тодорхой буцаасан нь нотлогдов.

## Нотолгоо (Evidence)
- `evidence/api-old-500-error.txt` — `curl -i /old` хариу (HTTP 500)
- `screenshots/` — browser дээр харагдсан "Internal Server Error"
  хуудасны screenshot

## Нэмэлт тэмдэглэл
Энэ нь API-ийн алдаа боловч шууд навигацийн линкээр хүрэх боломжтой
тул энгийн хэрэглэгч санамсаргүй байдлаар тааралдах магадлалтай. Lab-ийн
app нь оюутанд зориуд суулгасан алдаа учраас энэ нь "feature бус,
bug" гэж үзэж болно.
