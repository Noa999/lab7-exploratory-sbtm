# Bug 01 — "Нийт ном" тоолуур буруу тоологддог

**Severity:** High
**Олдсон аялал:** Couch Potato — "Бүгд" товчийг дарж жагсаалтыг энгийн байдлаар үзэхэд л "Нийт ном" тоолуурын зөрүү ажиглагдсан бөгөөд дараа нь curl-ээр баталгаажуулсан.
**Орчин:** Opera browser, Node.js, http://localhost:3000

## Урьдчилсан нөхцөл (Preconditions)
Апп энгийн байдлаар ажиллаж байгаа, өгөгдлийн санд (in-memory) ямар ч
тооны ном байж болно.

## Reproduce хийх алхмууд
1. `http://localhost:3000` хуудсыг нээх
2. Жагсаалтад байгаа номын тоог (хүснэгтийн мөрийг) гараар тоолох
3. Хуудасны доод хэсэгт байгаа "Нийт ном: X" гэсэн тоотой харьцуулах
4. Нэмэлтээр: `curl -i http://localhost:3000/api/books` ба
   `curl -i http://localhost:3000/api/stats`-г тус тусад нь дуудаж,
   буцсан жагсаалтын урт ба `total` талбарыг харьцуулах

## Хүлээгдэж буй үр дүн (Expected)
"Нийт ном" дээр харагдах тоо нь хүснэгтэд бодитоор байгаа номын тоотой
(мөн `/api/books`-ийн буцаасан массивын уртай) яг тэнцүү байх ёстой.

## Бодит үр дүн (Actual)
UI дээр "Нийт ном: 9" гэж харуулсан боловч хүснэгтэд бодитоор 8 ном
байв. API түвшинд баталгаажуулахад:
- `GET /api/books` → 8 элементтэй массив буцаасан (id 1–8)
- `GET /api/stats` → `{"total":9, ...}` буцаасан

Тоолуур бодит тооноос тогтмол 1-ээр их гарч байна.

- `evidence/api-books-list.txt` — `/api/books` хариу (8 ном)
- `evidence/api-stats-count-bug.txt` — `/api/stats` хариу (`total:9`)

  "Нийт ном: 9" текст, хүснэгтийн бодит 8 мөртэй зэрэгцүүлэн харуулсан
  screenshot

## Нэмэлт тэмдэглэл
Энэ зөрүү нь ном нэмэх/устгах бүрт тогтмол ажиглагдсан (анх 3 ном
байхад UI 4 гэж, дараа нь 8 ном байхад 9 гэж харуулсан), өөрөөр хэлбэл
тогтмол off-by-one алдаа бөгөөд тодорхой нэг тохиолдлын санамсаргүй
дата биш.
