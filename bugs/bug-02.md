# Bug 02 — Оролтын validation байхгүй: хоосон/зайтай ном нэмэгддэг

**Severity:** Medium
**Олдсон аялал:** Saboteur — Хоосон болон зөвхөн зай бүхий утгыг зориуд оруулж validation шалгасан үед илэрсэн.
**Орчин:** Chrome browser, Node.js, http://localhost:3000

## Урьдчилсан нөхцөл (Preconditions)
Апп энгийн байдлаар ажиллаж байгаа, "Нэмэx" товч ашиглах боломжтой.

## Reproduce хийх алхмууд
1. `http://localhost:3000` хуудсыг нээх
2. Гарчиг, Зохиолч, Он гурван талбарыг бүгдийг нь хоосон орхиод
   "Нэмэx" товчийг дарах
3. Үр дүнг ажиглах
4. Дараа нь 3 талбарт зөвхөн зай (" ") бичээд дахин "Нэмэx" дарах
5. Үр дүнг ажиглах

## Хүлээгдэж буй үр дүн (Expected)
Гарчиг эсвэл Зохиолч талбар хоосон (эсвэл зөвхөн зай) байх үед апп
алдааны мессеж харуулж, номыг жагсаалтад нэмэхгүй байх ёстой.

## Бодит үр дүн (Actual)
Хоёр тохиолдолд ч алдааны мессеж гараагүй бөгөөд хүснэгтэд огт
агуулгагүй (харагдахуйц гарчиг, зохиолчгүй) хоосон мөр нэмэгдсэн.
Сервер тал ч validation/trim хийдэггүй нь ажиглагдав — учир нь зай
("  ") агуулсан утга хадгалагдаад буцаж ирсэн.

давтагдсан (POST /api/books ямар ч validation хийдэггүй) тул frontend
дээр нэмэлтээр шалгасан ч гэсэн API-гаа дангаар нь дуудсан тохиолдолд
